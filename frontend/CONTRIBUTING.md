# Как править сайт ВИНОТЕРРА

Короткая инструкция: как поменять картинку, отредактировать текст карточки
или добавить новую страну — без знания JavaScript.

## Как устроен сайт

HTML-страницы (`world.html`, `russia.html`, …) — это пустые «каркасы».
Все карточки стран, регионов и сортов строятся скриптом из одного файла данных:

```
data/
  academy.json   ← Академия: сорта винограда, факты          (исходник, правится руками)
  russia.json    ← Россия и СНГ                              (исходник, правится руками)
  world.json     ← страны мира                               (исходник, правится руками)
  islands.json   ← острова                                   (исходник, правится руками)
  build.py       ← скрипт сборки
  wine-data.js   ← собранный файл, который читает сайт. РУКАМИ НЕ ПРАВИТЬ
```

Порядок любой правки данных:

1. Отредактируйте нужный `data/*.json` (обычный текстовый редактор или VS Code).
2. Выполните в папке проекта: `python data/build.py`
3. Обновите страницу в браузере — изменения на месте.
4. Закоммитьте и запушьте **оба** файла: и `.json`, и пересобранный `wine-data.js`.

## Поменять картинку

Код трогать не нужно. Картинка карточки ищется по имени: **префикс + id объекта**.

| Раздел              | Папка и префикс           | Пример                          |
|---------------------|---------------------------|---------------------------------|
| Страны мира         | `assets/img/w_`           | `w_southafrica.jpg`             |
| Россия и СНГ        | `assets/img/cis_`         | `cis_georgia.jpg`               |
| Острова             | `assets/img/i_`           | `i_madeira.jpg`                 |
| Карточки континентов| `assets/img/c_`           | `c_africa.jpg`                  |
| Флаги               | `assets/img/flags/`       | `flags/southafrica.svg`         |

Замена: положите новый JPEG под тем же именем поверх старого.
Рекомендуемый формат: квадрат ~1000×1000, качество 85 (вес до ~350 КБ).

## Добавить страну (пример: в Африку)

1. Откройте `data/world.json`, найдите массив `"countries"`.
2. Скопируйте любой объект-страну целиком (от `{` до `}`) и вставьте копию
   после последней африканской страны (сейчас это Мадагаскар). Заполните поля:

```json
{
  "id": "namibia",
  "continent": "africa",
  "name": "Намибия",
  "emoji": "🇳🇦",
  "tagline": "Виноградники на краю пустыни",
  "facts": [
    "Первый факт.",
    "Второй факт.",
    "Третий факт."
  ],
  "grapes": ["Коломбар", "Шираз"],
  "signature": "Долина Оранжевой реки",
  "buy": "Что купить, чтобы попробовать страну"
}
```

   - `id` — латиницей, без пробелов; по нему ищутся картинка и флаг;
   - `continent` — один из: `europe`, `asia`, `africa`, `namerica`, `samerica`, `oceania`;
     по нему карточка попадает под нужный фильтр;
   - не забудьте запятую между объектами в массиве.

3. Положите картинку `assets/img/w_namibia.jpg` и флаг `assets/img/flags/namibia.svg`
   (флаги удобно брать из https://github.com/lipis/flag-icons, папка `flags/4x3/`,
   файл переименовать в наш `id`). Без флага карточка тоже работает — покажется эмодзи.
4. `python data/build.py` — готово, карточка появится в сетке и в поиске сама.

Совет: сетка стран — по 3 в ряд, поэтому красивее всего, когда общее число
стран кратно трём (сейчас 48).

Аналогично добавляются регионы в `russia.json`, острова в `islands.json`
и сорта винограда в `academy.json` — структура объектов видна в самих файлах.

## Тексты страниц (не карточки)

Заголовки секций, баннеры, подвал — прямо в HTML-файлах страниц.
Общие стили — `assets/css/style.css`, общая логика (меню, поиск, карточки,
кнопка Нейро-сомелье) — `assets/js/main.js`. Адрес Telegram-бота задаётся
одной константой `TG_BOT` в начале `main.js`.

## Публикация

Сайт (vino-terra.ru) размещён на арендованном сервере: nginx раздаёт статику
из `frontend/`, а запросы `/api/*` проксирует на Python-бэкенд (Нейро-сомелье).
Инструкция по развёртыванию и обновлению — в `deploy/DEPLOY.md`.
